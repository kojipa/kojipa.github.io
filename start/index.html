日産アリアのバッテリーモニターはじめての Ariya Monitor

日産アリアで Ariya Monitor を始めるときに、よく聞かれる3つのことをまとめました。アプリは無料です。

スマホ？アリアの画面？ アダプターはどれ？ 古いAndroidでも大丈夫？ アリアの画面に出すには？ はじめの手順

スマホで使う？アリアの画面で使う？

Ariya Monitor は Android のアプリです。入れる先は、次のどちらかを選べます。

スマホ・タブレットに入れて使う
アリア挿す →アダプター無線 →Android端末

用意するもの：OBD2アダプター、Android端末（使っていない古い端末でもOK）

アリアの画面に出して使う
アリア挿す →アダプター無線 →AIボックスUSB →アリアの画面

用意するもの：OBD2アダプター、CarPlay AIボックス（Android端末は不要）

① OBD2アダプターはどれがおすすめ？

安定重視 Vgate vLinker MC+

少し高めですが、安定してつながります。迷ったらこちら。Bluetooth と BLE の両方に対応しています。

メーカーのページAmazonで探す
安く始める Zappa ELM327（Bluetooth 4.0 BLE・BT2.0 両対応）

作者が開発に使っているものです。

Amazonの商品ページ
  • アプリが使えるのは ELM327互換 のアダプターです。Bluetooth・BLE・Wi-Fi のどれでもつながります（Lite版は Bluetooth だけ）。
  • とても安い互換品の中には、空気圧・走行距離・外気温・ウインカーが読めないものや、だんだん遅くなるものがあります。
  • 「Bluetooth と BLE の両対応」のアダプターは、どちらか片方でしかつながりません。アプリの「設定」→「接続」で選んだほうを使います。
  • 挿しっぱなしにすると12Vバッテリーが減ることがあります。長く乗らないときは抜いてください。

リンク先の商品や値段は変わることがあります。買う前に、対応する接続方法（Bluetooth・BLE）を確かめてください。

② 使っていない古いAndroidでも大丈夫？

たいてい大丈夫です。Androidのバージョンで入れるアプリが変わります。

Androidのバージョン入れるアプリ使えるアダプター
8.0 以上Ariya Monitor（通常版）Bluetooth・BLE・Wi-Fi
5.0〜7Ariya Monitor Lite（軽量版）Bluetooth
  • バージョンは、端末の「設定」→「端末情報」（または「デバイス情報」）→「Androidバージョン」で見られます。
  • SIMカードは要りません。Bluetooth（Wi-Fiのアダプターなら Wi-Fi）が使えれば動きます。
  • 無料なので、まずは入れて開いてみるのがおすすめです。8.0以上でも、動きが重いと感じたら Lite版も試せます。

③ アリアの画面に出すには？

「CarPlay AIボックス」を使います。

  • アリアの画面では、Androidのアプリをそのまま動かすことはできません。
  • CarPlay AIボックスは、アリアのUSBにつなぐ小さなAndroid機器です。アリアの画面が Androidタブレットのようになり、そこに Ariya Monitor を入れて使えます。
  • AIボックスを使えば、別に Android端末を用意する必要はありません。
  • アダプターは、AIボックスの Bluetooth（または Wi-Fi）につなぎます。
AIボックス CarPlay AIボックス（有線CarPlay対応車用）

いろいろなメーカーから出ています。「有線CarPlayの車に対応」「Android 8.0以上」のものを選んでください。

Amazonで探す

AIボックスは機種によって中身の Androidバージョンや動きが違います。買う前に Android 8.0 以上かどうかを確かめてください。

はじめの手順

  1. アプリを入れるAndroid端末（またはAIボックス）のブラウザで、②の表のリンクから最新版のAPKをダウンロードして開きます。「提供元不明のアプリ」の許可を求められたら許可してください。
  2. アダプターを挿す車の電源を入れて、OBD2の差し込み口にアダプターを挿します。
  3. BluetoothのアダプターはペアリングAndroidの「設定」→「Bluetooth」でペアリングします（PINはたいてい 1234 か 0000）。BLE・Wi-Fiのアダプターはここは飛ばします。
  4. アプリでアダプターを選ぶアプリの「設定」→「接続」→「アダプター」の「変更」で、使うアダプターを選びます。
  5. つながったら完成ホーム画面にバッテリーの残量や電力が出てきます。次からはアプリを開くだけで自動でつながります。

つながらないときは

  1. ほかのOBDアプリ（Car Scanner など）を終了する（アダプターは同時に1つのアプリしかつながりません）
  2. アダプターを抜いて挿し直す
  3. 車の電源を入れ直す
